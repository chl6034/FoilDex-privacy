제9조 (광고 및 수익화)

본 앱은 서비스 운영을 위해 다음의 수익화 수단을 사용합니다.

  • Google AdMob 배너 광고: 메인 화면 하단에 표시
  • Google AdMob 보상형 광고: 카드 5장 저장 시마다 표시 (최소 60초 간격)

Google AdMob은 광고 최적화를 위해 광고 식별자(GAID), 기기 정보 등을 수집할 수 있습니다.

이용자는 기기 설정에서 광고 추적을 제한할 수 있습니다.

  • Android: 설정 > Google > 광고

제10조 (클라우드 백업 및 데이터 동기화)

앱은 이용자의 선택에 따라 다음 데이터를 Firebase Cloud에 백업할 수 있습니다.

  • 카드 컬렉션 데이터 (카드 정보 및 메타데이터)
  • 카드 이미지 (Firebase Storage에 압축 저장)
  • 팩/컬렉션 관리 데이터

백업은 이용자가 직접 실행하며, 최소 5분 간격으로 제한됩니다. 백업 데이터는 이용자의 Firebase 계정에 귀속되며, 계정 삭제 시 함께 파기됩니다.

제11조 (로컬 데이터 저장)

앱은 기기 내에 다음 데이터를 로컬로 저장합니다.

  • Hive 데이터베이스: 카드 컬렉션, 팩 관리, 커스텀 TCG 데이터 (계정별 분리 저장)
  • SharedPreferences: 앱 설정, 테마, 글꼴 크기, 사운드 설정 등
  • 로컬 이미지 파일: 카드 사진 (앱 전용 디렉토리에 저장)

로컬 데이터는 기기에서만 유지되며, 앱 삭제 시 함께 삭제됩니다. 계정 전환 시 데이터가 혼재되지 않도록 계정별(UID)로 분리 관리됩니다.

제13조 (개인정보의 안전성 확보 조치)

앱은 개인정보의 안전성 확보를 위해 다음과 같은 조치를 취하고 있습니다.

  • 데이터 암호화: Firebase 전송 시 SSL/TLS 암호화 적용
  • 접근 제한: Firebase Security Rules를 통한 데이터 접근 통제 (본인 데이터만 읽기/쓰기 가능)
  • 비밀번호 보호: Firebase Authentication의 보안 해시(bcrypt) 처리
  • 로컬 데이터 보호: 기기 내 저장 데이터는 앱 샌드박스 내 보관
  • 계정 분리: 멀티 계정 환경에서 UID 기반 데이터 격리

제14조 (자동 수집 장치의 설치/운영 및 거부)

앱은 웹 쿠키를 사용하지 않으나, 다음의 자동 수집 장치를 사용합니다.

  • Google AdMob SDK: 광고 식별자(GAID)를 자동 수집하여 맞춤형 광고 제공
  • Firebase Cloud Messaging: 푸시 알림용 기기 토큰(FCM Token) 수집

이용자는 기기 설정에서 광고 식별자 수집을 거부할 수 있으며, 푸시 알림은 기기 설정에서 끌 수 있습니다.
