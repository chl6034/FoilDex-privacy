계정 및 데이터 삭제 요청

FoilDex — 카드 컬렉션 관리 앱

FoilDex는 기본적으로 모든 데이터를 사용자 기기에 로컬로 저장합니다. 구글 로그인은 선택 사항이며, 로그인한 경우에만 클라우드 백업/복원을 위해 일부 데이터가 클라우드(Google Firebase)에 저장됩니다. 아래 방법으로 계정과 데이터를 삭제할 수 있습니다.

1. 앱에서 직접 삭제 (권장)

클라우드 데이터 + 계정 삭제
  • FoilDex 앱 실행 → 설정 → 클라우드 → 계정·데이터 삭제
  • 클라우드에 저장된 모든 카드·이미지와 구글 계정 연결이 영구 삭제됩니다.
기기 로컬 데이터 삭제
  • 설정 → 데이터 초기화 를 사용하거나, 앱을 삭제(제거)하면 기기에 저장된 모든 로컬 데이터가 제거됩니다.

2. 이메일로 삭제 요청 (앱을 사용할 수 없는 경우)
